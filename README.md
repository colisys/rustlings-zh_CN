使用指南：

1. 克隆仓库
2. 使用 `cargo build` 构建 rustlings
3. 执行 `./target/debug/rustlings lsp`，生成项目文件，以便开发环境可以正确的给出语法提示
4. 使用你的开发环境，打开本仓库的根目录
5. 开启一个命令行窗口，运行 `./target/debug/rustlings` 命令

然后就可以开始解题了。

Rustlings 已经按照以一定的顺序把题目排列了，如果不清楚要做什么的话，可以在运行有 Rustlings 的命令行窗口按 `l` 键，查看有什么题目可以做。
